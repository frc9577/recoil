# recoil prototypes

Off-season prototypes, examples and experiments for FRC 9577 "Recoil". Each top-level directory is one WPILib project. Code here is not guaranteed to build.

This branch shares no history with `development` or `main`. Branch from here and open PRs with base `prototypes`. GitHub sets the PR base to `main` by default, so change it. Never merge this branch into `development` or `main`.

The competition code is on `development` and `main`. See README.md there.
